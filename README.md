# Проект "ProjectBank"

## Описание:

Проект "ProjectBank" - это приложение, которое позволяет скрыть номер вводимой Вами карты или банковсколго счета, отсортировать вводимые списки по дате и признаку состояния.

## Декораторы:

Добавлены декораторы и тесты для проверки их поведения

## Генераторы:

Добавлены генераторы тестовых данных для проверки правильности работы функций приложения

## Чтение .csv и .xlsx файлов

Приложение может работать с файлами формата .csv и .xlsx

## Тестирование:

Добавлена папка с тестами, проверяющими функционал приложения

## Установка:

Клонируйте репозиторий:
```https://github.com/mazzzay73-crypto/ProjectBank/tree/feature/homework_10_1```

## Использование:

1. Введите номер Вашей карты или банковского счета
2. Введите дату
3. Введите список Ваших словарей
